# Employee Attrition Prediction

This project builds machine learning models to predict employee attrition using historical employee data. Early prediction helps HR teams identify employees likely to leave and implement retention strategies to reduce turnover costs.

## Dataset

- Source: [IBM HR Analytics Employee Attrition & Performance](https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset) from Kaggle  
- Features include employee demographics, job role, satisfaction, tenure, compensation, and performance metrics.

## Technologies Used

- **Python** – Core programming language  
- **Jupyter Notebook** – Interactive coding and documentation  
- **Pandas / NumPy** – Data manipulation and preprocessing  
- **Scikit-learn** – Machine learning modeling and evaluation  
- **Matplotlib / Seaborn** – Exploratory data analysis and visualization  

## Key Features

- Data cleaning and preprocessing including encoding categorical variables  
- Exploratory Data Analysis (EDA) to understand attrition patterns  
- Machine learning models including Random Forest, Logistic Regression, and Decision Tree Classifier to predict employee attrition  
- Feature importance analysis to identify the most influential factors driving attrition  
- Model evaluation using accuracy, precision, recall, F1-score, and confusion matrix
